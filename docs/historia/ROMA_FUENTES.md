# Primera historia: expansión de Roma

Estado: selección inicial de contenido, pendiente de revisión histórica adicional e implementación. Fecha de consulta: 2026-11-15.

Alcance acordado: expansión de Roma; para esta primera narración se propone el periodo desde la República hasta el inicio del Principado. La expansión fue un proceso prolongado que incluyó conquista y diplomacia; estos hitos no son una reconstrucción exhaustiva ni una frontera territorial.
